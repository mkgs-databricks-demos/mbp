## Definition

A transaction generated by a store cash register or workstation ([Oracle Retail](https://download.oracle.com/oll/tutorials/OCDMTutorial/html/start_here/glossary.htm)).

## Business context

This is the grain of the sales fact table.

## Data usage

Source tables: samples.bakehouse.sales_transactions

One row per transactionID, dated by dateTime; grain to be confirmed by EDA.
